# Silent Hill Discord RPC

A lightweight Windows System Tray application that provides clean Discord Rich Presence for emulated Silent Hill games.

The presence displays strictly:
* **Playing [Game Title]**
* **Elapsed Time**
* **Large Cover Icon**
* **Small Platform / Loader Icon**

---

## Usage

1. Launch `SilentHillEmulatorRPC.exe`.
2. The app docks in your **Windows System Tray**..
3. Right-click the tray icon to:
   * View live detection status.
   * **Toggle game detection on/off** with checkboxes.
   * Open `appsettings.json` or the `img/` assets folder.
   * Exit the application.
